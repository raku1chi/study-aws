# Phase 1: 基礎（IT の基礎 + クラウドの基礎） ― 目標: CLF-C02

AWS を「なんとなく使える」ではなく「仕組みから理解できる」ようになるための土台づくりのフェーズです。
前半（1〜3 章）で **ネットワーク・サーバー・セキュリティ・データベース** という IT の基礎を固め、
後半（4〜9 章）で **クラウドの概念と AWS の全体像** を学び、AWS Certified Cloud Practitioner（CLF-C02）の合格を目指します。

> [!TIP]
> Phase 2 以降で「難しい」と感じる内容の多くは、実はこのフェーズで扱う基礎（特に CIDR、DNS、暗号化、トランザクション）の理解不足が原因です。
> IT 経験者も、1〜3 章の確認問題だけは必ず解いてみてください。

## このフェーズのゴール

- TCP/IP・DNS・HTTP の仕組みを説明でき、CIDR からアドレス数を計算できる
- 仮想化・コンテナ・サーバーレスの違いと、可用性（稼働率・RPO/RTO）の考え方を説明できる
- 認証と認可、暗号化、RDB と NoSQL の違いを説明できる
- クラウドの利点、責任共有モデル、AWS のグローバルインフラを説明できる
- 主要な AWS サービスの役割を一言で説明できる
- AWS の料金モデル、コスト管理ツール、サポートプランを説明できる
- CLF-C02 の模擬試験で 80% 以上を取れる
