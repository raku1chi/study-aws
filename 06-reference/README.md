# リファレンス

学習中にいつでも引ける資料集です。章を読みながら、また試験直前の総仕上げに使ってください。

| 資料 | 内容 | おすすめの使い方 |
|---|---|---|
| [用語集](glossary.md) | AWS と IT の用語を簡潔に解説 | わからない用語が出たらすぐ引く |
| [サービス早見表](service-cheatsheet.md) | 主要サービスを一行で説明、出題レベル付き | 「一言で説明できるか」の自己チェック |
| [比較表集](comparison-tables.md) | 紛らわしいサービス・機能の使い分け | 章を読み終えた後の整理、直前の見直し |
| [覚えておきたい数値](numbers-to-remember.md) | 上限値・期間・サイズなど | 間隔反復で少しずつ覚える |
| [問題文キーワード → 解答 対応表](exam-keywords.md) | 問題文の手がかりと定番の解答 | 模擬試験の後、試験直前 |
| [サービスの変更点（2024–2026）](service-changes.md) | 廃止・名称変更・新サービス | 古い書籍や問題集を使う前に必ず確認 |
| [学習リソース集](resources.md) | 公式ドキュメント、日本語資料、問題集 | 教材の範囲を超えて深掘りしたいとき |

> [!WARNING]
> AWS の数値（上限値・料金など）は頻繁に変わります。本教材の数値は 2026 年 9 月時点のものです。
> 実務で使う場合は必ず公式ドキュメントで最新の値を確認してください。
