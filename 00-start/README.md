# Phase 0: はじめに

本格的な学習に入る前に、**学び方・目標・環境** の 3 つを整えるフェーズです。
ここを丁寧に済ませておくと、その後の数か月の学習効率が大きく変わります。

## このフェーズのゴール

- この教材の使い方と、効果的な学習サイクルを理解している
- AWS 認定の体系と、目指す試験（CLF-C02 → SAA-C03 → SAP-C03）の仕組みを知っている
- 自分に合った学習計画と、試験日の目安を決めている
- MFA と予算アラートを設定した、安全な学習用 AWS アカウントを持っている

## 完了の目安

- [ ] 学習計画を立て、カレンダーに学習時間を確保した

- [ ] 日常の作業用に、ルートユーザー以外の管理用ユーザー（MFA 付き）でサインインできる
