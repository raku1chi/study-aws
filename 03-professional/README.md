# Phase 3: プロフェッショナル ― 目標: SAP-C03

複数アカウント・ハイブリッド環境・グローバル規模のシステムについて、**複数の要件と制約のトレードオフを判断し、最適な設計を選べる** ようになるフェーズです。
AWS Certified Solutions Architect – Professional（SAP-C03）の合格を目指します。

> [!IMPORTANT]
> SAP-C03 は 2026-11-17 に提供開始される新バージョンです（SAP-C02 の最終受験日は 2026-11-16）。
> 公式の試験ガイド（タスクステートメントとドメインの配点）は **2026-10-27 に公開予定** です。
> 本フェーズは発表済みの 5 ドメインと追加領域に基づいて構成しています。公開後は公式ガイドと本フェーズの対応を必ず確認してください。

## SAA との違い

| 観点 | SAA-C03 | SAP-C03 |
|---|---|---|
| 対象範囲 | 単一アカウント・単一ワークロードが中心 | 組織全体（数十〜数百アカウント）、ハイブリッド、マルチリージョン |
| 問われ方 | 「どのサービスを使うか」 | 「複数の制約を同時に満たす最適な組み合わせはどれか」 |
| 問題文 | 短〜中程度 | 長文（関係者、既存環境、制約が多数） |
| 選択肢 | 誤りの選択肢が見分けやすい | どの選択肢も「動く」。コスト・運用負荷・移行リスクで差がつく |
| 試験時間 | 65 問 / 130 分 | 75 問 / 180 分（集中力の持続が課題） |

## このフェーズのゴール

- マルチアカウント環境のガバナンス（OU 設計、SCP / RCP、Control Tower）を設計できる
- 大規模なネットワーク（Transit Gateway、Direct Connect、ハイブリッド DNS、VPC Lattice）を設計できる
- 組織全体のセキュリティ（検出の集中化、自動修復、暗号鍵の設計）を設計できる
- RPO/RTO に応じたマルチリージョン構成と、その検証方法（FIS、Resilience Hub、ARC）を選べる
- 大規模移行の戦略（7R、ツール選定、段階的移行）を立てられる
- 生成 AI・エージェント AI、レイクハウスを含むクラウドネイティブなアーキテクチャを設計できる
- SAP-C03 の模擬試験で 75% 以上を取れる
